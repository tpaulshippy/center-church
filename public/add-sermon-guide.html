How to add
a sermon episode.

Publish a Sunday sermon to Spotify for Creators and it shows up on centergilbert.com/sermons automatically.

Start: centergilbert.com/add-sermon →

Fallback: creators.spotify.com/pod/show/4bPRAwHcRw08NO9uQWWtty/episodes

Step 1

Open the Episodes page

Go to centergilbert.com/add-sermon. It takes you to the Episodes page for Center Church | Gilbert Sermons in Spotify for Creators. Log in if it asks you to.

Step 2

Click “New episode”

On the Episodes page, click the New episode button in the top-right corner.

Step 3

Upload the audio

Drag and drop your file onto the upload area, or click Select a file to browse. Accepted types: mp3, m4a, wav, mpg, mp4, mov. Wait for the upload to finish before moving on.

Step 4

Fill in the details

  • Title: use the sermon title as-is (for example “Acts 19:21-41” or “Ask God Anything: …”). Our book series preach verse-by-verse, so keep the book and passage at the start.
  • Description: the first line matters most — see the box below.
  • Episode art: click Change and set the current series artwork, not the default church logo.
  • Explicit / content rating: No — clean.
The first line of the description must be the speaker

Start the description with exactly this line (the website uses it for the speaker filter and hides it from display — see PUBLISHING.md for why Spotify needs this):

Speaker: Full Name — for example Speaker: Rich Richardson. Use the full name as it appears on the site, not “Pastor Rich”. Then leave a blank line before the rest.

Copy-paste template

Description template

Copy this into the description box and fill in the blanks:

Speaker: [Full Name] [Passage / Series — e.g. Acts 19:21-41 | Center Church] [1-2 sentence summary]
Step 5

Review and publish

On the Review screen, under Schedule, select Schedule (not Now) and set the Date and Time to when the sermon started — for example, the Sunday morning service time. Then hit Publish. New episodes appear on centergilbert.com/sermons within about 5 minutes. If the speaker filter misses it, check the description’s first line first.

Troubleshooting

If something looks wrong

  • Upload stuck? Check the file type and size, then try again. Supported files are mp3, m4a, wav, mpg, mp4, and mov.
  • Wrong speaker on the site? Open the episode in Spotify for Creators and fix the first line of the description — it must read Speaker: Full Name exactly.
  • Episode not on the site yet? Wait about 5 minutes, then do a hard refresh (Ctrl/Cmd + Shift + R).
